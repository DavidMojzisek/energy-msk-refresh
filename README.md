# Bilance elektřiny Moravskoslezského kraje

Interaktivní stránka o výrobě a spotřebě elektřiny v Moravskoslezském kraji do roku 2050 ve dvou možných cestách. Je to cvičení metody scénářů, ne prováděcí plán.

Stránka: https://davidmojzisek.github.io/energy-msk-refresh/

Soubor `realisticky.json` obsahuje data třetí křivky, realistického scénáře. Při sestavení se vkládá do stránky.

Hodnoty po roce 2025 jsou odhady. Písma Saira, DM Sans a JetBrains Mono jsou pod licencí SIL Open Font License.
