# Bilance elektřiny MSK

Interaktivní prototyp výroby a spotřeby elektřiny v Moravskoslezském kraji do roku 2050 ve dvou možných cestách.

Stránka: https://davidmojzisek.github.io/energy-msk-refresh/

Hodnoty po roce 2025 jsou odhady a čekají na ověření. Písma Saira, DM Sans a JetBrains Mono jsou pod licencí SIL Open Font License.

Úprava dat: změňte `polozky.csv` a spusťte `python3 build.py`.
